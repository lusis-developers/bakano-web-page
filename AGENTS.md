# AGENTS.md — Bakano Webpage

Compact guide for OpenCode sessions working on this Vue 3 + Vite site.

## Tech stack

- Vue 3 (Composition API, `<script setup lang="ts">`), Vue Router, Pinia
- Vite 7, TypeScript 5.8, `vue-tsc` for type checking
- Sass/SCSS with auto-injected variables
- pnpm (lockfile: `pnpm-lock.yaml`)
- Node `^20.19.0 || >=22.12.0`

## Commands

```sh
pnpm install
pnpm dev          # Vite dev server
pnpm build        # runs type-check + build-only in parallel
pnpm build-only   # Vite production build without type check
pnpm type-check   # vue-tsc --build
pnpm preview      # preview production build
pnpm format       # prettier --write src/
```

## Important conventions

- **Use `vue-tsc`, not `tsc`**, for type checking. TypeScript cannot resolve `.vue` imports without it.
- **`pnpm build` runs `type-check` and `build-only` in parallel** via `npm-run-all2`. If type-check fails, the build fails.
- **No test runner is configured.** `tsconfig.node.json` references `vitest.config.*`, but there is no Vitest dependency or config yet.
- **Path alias:** `@/` maps to `src/` (configured in both `vite.config.ts` and `tsconfig.app.json`).
- **Global SCSS variables are auto-injected.** Vite loads `@use "@/styles/colorVariables.module.scss" as *;` into every `<style lang="scss">` block. Prefer these `$BAKANO-*` tokens over hardcoded colors.
- **Prettier settings:** `semi: false`, `singleQuote: true`, `printWidth: 100`. Run `pnpm format` before committing style-heavy changes.

## Entry points

- App mount: `src/main.ts`
- Root component: `src/App.vue`
- Router + per-route SEO meta: `src/router/index.ts`
- Global styles: `src/styles/global.scss` (imported in `main.ts`) and `src/styles/index.scss`

## Build / deploy notes

- `dist/` is gitignored. Production output is generated by `vite build`.
- `index.html` contains hardcoded SEO, Meta Pixel, JSON-LD, and canonical tags for `https://bakano.ec/`. Per-route meta is updated client-side in `src/router/index.ts`.
- Dev server `allowedHosts` in `vite.config.ts` includes a specific ngrok host; update it if you need to expose a different tunnel.
- Vue DevTools plugin is enabled in dev via `vite-plugin-vue-devtools`.
